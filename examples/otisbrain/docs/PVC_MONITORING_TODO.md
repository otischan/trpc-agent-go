# PVC监控功能待办清单

## 背景

在2026年2月2日的开发过程中，我们曾计划实现PVC（PersistentVolumeClaim）监控功能，旨在监控PVC的存储使用率并在超过阈值时生成告警。然而，由于技术限制，该功能最终被移除。

## 问题分析

### 当前限制
1. **Kubernetes API限制**：标准Kubernetes API不提供PVC的实际使用率数据
2. **存储提供商依赖**：实际使用率数据依赖特定存储提供商的API
3. **CSI驱动限制**：需要特定的CSI驱动支持才能获取使用率指标
4. **监控价值有限**：仅监控PVC绑定状态（Bound/Pending）对运维价值不大

### 无法实现的核心需求
- 监控PVC的存储使用率（实际已用容量/总容量）
- 当使用率超过阈值（如80%）时生成告警
- 查询使用该PVC的Pod列表
- 限制显示的Pod数量（如最多显示5个）
